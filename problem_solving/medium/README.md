# Medium Problems

This tier assumes fundamentals are solid. A **medium** problem here means:

- Combines **2-3 concepts** (e.g. hashing + sliding window, or recursion + memoization), or
- Requires you to find an **efficient algorithm** rather than the first brute-force idea that comes to mind (typically improving from O(n²) to O(n log n) or O(n)).
- Often involves a non-trivial data structure: trees, graphs, heaps, or a DP table.
- Should take **20-40 minutes**, including time spent realizing the naive approach is too slow.

If a problem here feels easy, you've probably internalized the pattern — good sign, move faster.
