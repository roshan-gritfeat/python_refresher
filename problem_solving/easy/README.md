# Easy Problems

This tier is for warming up. An **easy** problem here means:

- Tests a **single concept** (one data structure or one technique), not a combination.
- Solvable with a **straightforward brute-force or direct approach** — no need to find a clever optimization.
- Should take a competent beginner/intermediate Python programmer **under 15 minutes** to solve once the idea clicks.
- Focuses on fundamentals: basic loops/recursion, string/list manipulation, simple use of `dict`/`set`/`list`/`stack`/`queue`, and basic math/logic.

Work through these to build fluency with Python syntax and the standard library before moving to `medium/`.
